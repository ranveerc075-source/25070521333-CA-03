# FLEXI Parking — Frontend Client (React)

This folder contains the complete React.js frontend built with Vite.

## Files
- `src/main.jsx` — React Dashboard, Login/Register pages, modals, state management.
- `src/styles.css` — Responsive design styling, modals, badges, cards.
- `index.html` — HTML shell.
- `vite.config.js` — Vite configuration with `/api` proxy pointing to `http://localhost:5000`.
- `dist/` — Compiled production build.

## Commands
```powershell
npm run dev     # Starts Vite development server on port 5173
npm run build   # Compiles production assets into dist/
```
